# QuickMark

自分用のシンプルなスクリーンショット注釈アプリ（Shottr 風）。Swift / AppKit + SwiftUI 製の macOS メニューバー常駐アプリです。

1. `⌘⇧2` で範囲を選んで撮影（macOS 標準の `screencapture -i` を利用。Space でウインドウ撮影に切替）
2. 撮影直後に編集ウインドウが開く
3. 矢印・四角・テキストを書き込む
4. `⌘C` で編集済み画像をクリップボードへコピーしてウインドウを閉じる → 好きなアプリで `⌘V`

## 操作

| キー | 動作 |
| --- | --- |
| `⌘⇧2` | 範囲を撮影して編集（どのアプリからでも） |
| `V` / `A` / `R` / `T` | 選択・移動 / 矢印 / 四角 / テキスト |
| `⌘Z` / `⇧⌘Z` | 取り消す / やり直す |
| `Delete` | 選択中の注釈を削除 |
| `⌘C` | 合成した画像をコピーして閉じる |
| `Esc` / `⌘W` | 保存せずに閉じる |

- 選択ツールで注釈をドラッグして移動。テキストはダブルクリック（またはテキストツールでクリック）で再編集。
- 注釈を選択中に色を押すと、その注釈の色を変更。
- メニューバーアイコンから「クリップボードの画像を編集」「画像ファイルを開く…」も使えます。

## ビルド

要件: macOS 13 以降、Xcode 15 以降（または Swift 5.9 以降のツールチェイン）。

```sh
./scripts/build-app.sh
cp -R build/QuickMark.app /Applications/
open /Applications/QuickMark.app
```

開発時は `open Package.swift` で Xcode で開き、そのまま Run できます（`swift run` でも起動可）。

### 初回の権限

初めて撮影すると「画面収録」の許可を求められます。
**システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音** で QuickMark を許可してください。
アドホック署名のため、再ビルドすると許可を付け直す必要がある場合があります。

## 構成

| ファイル | 役割 |
| --- | --- |
| `AppDelegate.swift` | メニューバー常駐、グローバルショートカット、編集ウインドウ管理 |
| `HotKeyManager.swift` | Carbon `RegisterEventHotKey` による `⌘⇧2`（アクセシビリティ権限不要） |
| `CaptureManager.swift` | `screencapture -i` で撮影、画像読み込み |
| `AnnotationModel.swift` | 矢印・四角・テキストのデータ、座標、Undo/Redo |
| `EditorCanvasView.swift` | 画像表示とマウス操作 |
| `EditorWindowController.swift` | 編集ウインドウと SwiftUI ツールバー |
| `AnnotationRenderer.swift` | 注釈の描画（画面表示と書き出しで共通）、合成とクリップボードへのコピー |

設計上のポイント:

- 注釈は元画像とは別に保持するので、後から移動・修正できます。コピー時に初めて合成します。
- 注釈の座標は「元画像のピクセル座標」で保存します。Retina でも表示サイズではなく元のピクセルサイズで合成するので、解像度は落ちません。
- 画面表示と書き出しは同じ描画コードを使うので、見たままの結果になります。
